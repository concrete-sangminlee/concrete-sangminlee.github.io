## Current Research Projects

### 1. Lightweight Machine Learning Models for Concrete Crack Image Classification
- Developing efficient deep learning models for automated crack detection in concrete structures
- Focus on model compression and optimization for edge device deployment
- Integration with real-time monitoring systems

### 2. Multi-class Deep SVDD for Concrete Building Monitoring
- Anomaly detection in structural health monitoring using deep learning
- Development of multi-class support vector data description models
- Real-time structural damage assessment

### 3. Large Language Model Framework for Structural Design Codes
- Development of domain-specific language models for structural engineering
- Integration of expert knowledge with transformer architectures
- Automated code compliance checking

### 4. Neural Network-based Wind Speed Prediction
- Satellite image analysis for wind speed estimation
- Deep learning models for wind engineering applications
- Integration with structural design processes

### 5. Automated Impact-Echo Testing
- Machine learning-based signal processing for non-destructive testing
- Automated defect detection in concrete structures
- Real-time quality assessment

### 6. Machine Learning for Concrete Compressive Strength Prediction
- Development of predictive models for concrete strength
- Integration of material properties and environmental factors
- Optimization of mix design

### 7. LSTM RNN for Wind Pressure Coefficient Prediction
- Time-series analysis of wind pressure data
- Deep learning models for aerodynamic analysis
- Application to high-rise building design
