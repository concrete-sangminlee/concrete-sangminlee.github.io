Presented our research on using Retrieval Augmented Generation (RAG) for assisting engineers in using wind load design codes. The system combines large language models with retrieval mechanisms to provide accurate and context-aware assistance.

**Key Points:**
- RAG architecture for engineering standards
- Integration with wind load design codes
- Improved accuracy in code interpretation
- Practical tool for engineering practice
