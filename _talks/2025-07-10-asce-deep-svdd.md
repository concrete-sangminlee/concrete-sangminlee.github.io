Presented our novel approach to structural health monitoring using multiclass Deep SVDD. The method achieves 88.11% accuracy in defect detection using only normal condition data, significantly outperforming traditional methods (58.68% accuracy).

**Key Points:**
- Semisupervised deep learning for anomaly detection
- Kernel density estimation integration
- Real-time defect detection framework
- Validation using shake table experiment data

**Publication:** ASCE Journal of Structural Engineering (2025)
