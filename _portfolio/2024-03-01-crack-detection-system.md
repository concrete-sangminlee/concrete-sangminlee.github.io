This project developed an AI-based system for automated concrete crack detection. The system features:

- Lightweight deep learning model optimized for edge devices
- Real-time processing capabilities
- High accuracy in crack detection
- Integration with existing structural health monitoring systems

**Technologies Used:**
- TensorFlow Lite
- OpenCV
- Python
- Edge TPU

**Key Features:**
1. Model compression and optimization
2. Real-time image processing
3. Automated crack classification
4. Integration with monitoring systems

**Impact:**
- Reduced inspection time by 80%
- Improved detection accuracy
- Enabled real-time monitoring
- Reduced maintenance costs
