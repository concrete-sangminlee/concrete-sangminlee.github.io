This project was developed during my internship at Waddle Corporation (Gentoo). The system features:

- **LLM-based Evaluation System**: Automated evaluation using large language models
- **User Simulator**: Realistic user interaction simulation for testing
- **Human Alignment**: Alignment of LLM evaluator with human judgment
- **Scalable Architecture**: Designed for production deployment

**Technologies Used:**
- Python
- PyTorch
- Transformers (Hugging Face)
- FastAPI
- PostgreSQL

**Key Features:**
1. User behavior simulation
2. LLM-based evaluation pipeline
3. Human feedback integration
4. Performance metrics tracking

**Impact:**
- Improved evaluation consistency
- Reduced manual evaluation time
- Enhanced scalability of evaluation systems
- Better alignment with human judgment

**Period:** September 2024 - February 2025  
**Company:** Gentoo (Waddle Corporation)  
**Role:** Machine Learning Engineer (Intern)
