This project developed an AI-based system for detecting internal defects in concrete structures. The system has been patented and applied to PCT, US patent, and EU patent.

**Key Features:**
- Automated impact-echo test result classification
- Real-time defect detection
- Multiple defect type classification
- Integration with existing inspection workflows

**Technologies Used:**
- Deep Learning (CNN, LSTM)
- Signal Processing
- Python
- Embedded Systems

**Impact:**
- Improved inspection efficiency
- Reduced human error
- Standardized defect detection
- Enabled automated monitoring

**Patent:** 1020230000782 (Korea, PCT, US, EU)
