Developed as part of the Smart City Innovative Technology Demonstration Project (2024-2025), this system integrates IoT sensors with AI-based analysis for urban infrastructure monitoring.

**Key Features:**
- Multi-sensor data collection (Arduino, ESP32, STM32)
- Real-time data transmission
- AI-based anomaly detection
- Cloud-based data storage and analysis
- Dashboard for monitoring and visualization

**Technologies Used:**
- IoT Hardware (Arduino, ESP32, STM32)
- Python
- Machine Learning
- Cloud Computing (AWS)
- Web Dashboard (React)

**Impact:**
- Real-time infrastructure monitoring
- Early warning system for structural issues
- Data-driven decision making
- Reduced maintenance costs

**Funding:** KAIA, MOLIT
