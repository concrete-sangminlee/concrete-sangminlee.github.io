This project developed an AI-based system for estimating wind loads on structures. The system features:

- Satellite image analysis for wind speed prediction
- Deep learning models for wind pressure estimation
- Integration with structural design processes
- Real-time wind load monitoring

**Technologies Used:**
- TensorFlow
- OpenCV
- Python
- AWS

**Key Features:**
1. Satellite image processing
2. Wind speed prediction
3. Wind pressure coefficient estimation
4. Real-time monitoring

**Impact:**
- Improved wind load estimation accuracy
- Reduced design time
- Enhanced structural safety
- Automated monitoring system
