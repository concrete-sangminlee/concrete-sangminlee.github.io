        게임 규칙 · 단축키

        목표

        팀 색 칩으로 연속 5칸 시퀀스 2개를 먼저 만드는 팀이 이깁니다. 코너 ★는 모든 팀이 공유하는 자동 칩입니다.

        턴 진행

        1. 손패에서 카드를 선택합니다.
        2. 보드에서 강조된 칸을 눌러 칩을 놓거나 잭 액션을 실행합니다.
        3. 사용한 카드를 버림 더미에 놓습니다.
        4. 덱에서 새 카드를 뽑으면 턴이 끝납니다.

        잭(J) 특수 규칙

        • J♣ · J♦ · 와일드빈 칸 어디든 내 팀 칩을 놓을 수 있습니다(코너 제외).
        • J♥ · J♠ · 컷상대 팀의 잠기지 않은 칩을 제거합니다. 시퀀스 칩은 보호됩니다.

        죽은 카드

        보드에 둘 곳이 없는 숫자/그림 카드는 죽은 카드 버리기 버튼으로 제거하고 새 카드를 뽑을 수 있습니다.

        키보드 · 접근성

        • 손패에서 ← → ↑ ↓로 카드 이동, Enter로 선택.
        • 카드 선택 후 ← → ↑ ↓로 보드 커서 이동, Enter/Space로 확정.
        • Esc로 선택 취소 또는 열린 모달 닫기, A로 가장 먼저 쓸 수 있는 카드 선택, B로 첫 수 자동 실행.
        • C로 현재 방 초대 링크 복사, F로 전체화면 전환, R로 리매치(동의/시작).

        개인정보 처리방침

        • 수집 항목: 입력하신 닉네임(메모리에 일시 보관), 접속 IP(연결 제한·보안 로그용), 자동 발급 세션 ID(브라우저 localStorage). 이메일·전화번호·실명은 받지 않습니다.
        • 보관 기간: 닉네임과 세션 정보는 방을 닫거나 브라우저를 끄면 즉시 사라집니다. 종료된 매치 기록(점수·승패)은 서버 디스크에 최대 12경기, 200개 방까지만 저장됩니다.
        • 제3자 제공: 없음. Google Analytics 등 외부 추적 도구를 사용하지 않으며, 수집한 정보는 본 게임 운영 목적 외에 활용하지 않습니다.
        • 이용자 권리: 브라우저 설정에서 사이트 데이터를 지우면 닉네임·세션 ID 등 클라이언트 측 정보가 모두 삭제됩니다. 서버에 저장된 매치 기록은 시간이 지나면 자동 폐기됩니다.
        • 보안 조치: 정적 배포는 GitHub Pages HTTPS로 제공됩니다. 자세한 보안 정책은 security.txt를 참고하세요.
